## Component Plan

### Phase 1 — 全部並行（13 個修改，0 個新增）

#### C1 — settings.json：啟用 hooks 並加入 hooks 區塊
- **動作：** 修改
- **檔案：** `.claude/settings.json`
- **內容：** 加入 `"hooks"` 區塊，啟用 `post-edit-build` hook（PostToolUse on Edit/Write for **/*.cs）
- **修復弱點：** W2（hooks 全部停用）
- **執行工具：** 直接 Edit

```json
"hooks": {
  "PostToolUse": [
    {
      "matcher": "Edit|Write",
      "hooks": [
        {
          "type": "command",
          "command": "dotnet build --no-restore",
          "timeout": 60000
        }
      ]
    }
  ]
}
```
